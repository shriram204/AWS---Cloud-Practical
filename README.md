# ☁️ AWS Cloud Practicals

A hands-on collection of AWS cloud computing practicals covering identity
and access management, compute, storage, networking, databases, and
serverless computing.

## 🎯 Objective

The objective of this project is to gain hands-on experience with Amazon
Web Services (AWS) by configuring and working with different AWS services
through practical exercises.

## 🛠️ Technologies & Services

| Technology / Service | Purpose |
|---|---|
| AWS Management Console | Manage AWS resources |
| AWS CLI | Command-line interaction with AWS |
| IAM | Identity and access management |
| MFA | Account security |
| Amazon EC2 | Cloud computing and server hosting |
| Windows Server | EC2-based web server |
| Amazon S3 | Object storage |
| S3 Static Website Hosting | Static website deployment |
| Amazon VPC | Virtual networking |
| VPC Peering | Communication between VPCs |
| Amazon RDS | Managed relational database |
| AWS Lambda | Serverless computing |
| S3 Event Trigger | Event-driven Lambda execution |
